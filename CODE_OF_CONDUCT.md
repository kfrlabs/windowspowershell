# Code of Conduct

This project welcomes contributions from everyone. By participating -- filing
issues, opening pull requests, commenting, or reviewing -- you agree to:

- be respectful and assume good intent, even in disagreement;
- stay on topic (the module, its tests, its docs) and keep criticism
  technical, never personal;
- respect the maintainers' time: search existing issues first, provide the
  reproducer the templates ask for, and keep the CI checklist green.

Unacceptable behaviour includes harassment, insults, demeaning comments,
publishing private information without consent, and any conduct that would
reasonably make a contributor feel unsafe or unwelcome.

Enforcement: report unacceptable behaviour via GitHub **private
vulnerability reporting** (or a private message to a maintainer) so the
report stays confidential. Maintainers will investigate and respond -- up
to and including removing content and temporarily or permanently banning
participants -- and will credit reporters only with their consent.

This is a deliberately short code of conduct for a small infrastructure
module; the goal is predictable, low-drama collaboration, not legalism.
